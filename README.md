# Elf Theme for Omarchy

A rich, earthy, dark-fantasy theme for **Omarchy** and **Hyprland**, featuring deep forest tones, moss-green accents, and warm highlights.

---

## 🎨 Color Palette

| Tone | Hex Code | Visual Swatch |
| :--- | :---: | :--- |
| **Background** | `#00070d` | Deep Void Dark |
| **Active Accent / Hair Green** | `#7fa961` | Vibrant Moss Green |
| **Highlight Green** | `#8db86b` | Leaf Highlight |
| **Foreground / Text** | `#ECF0E9` | Crisp Pale Linen |
| **Muted Border** | `#646a6e` | Slate Charcoal |
| **Warm Earth / Red** | `#b67443` | Terracotta Clay |
| **Soft Blue** | `#5380bd` | Dusk Blue |

---

## 🚀 Installation

Clone and install with one command:

```bash
git clone https://github.com/Sairnaq/omarchy-theme-elf.git ~/.config/omarchy/themes/elf
omarchy theme set elf
```

Or run the installer:
```bash
git clone https://github.com/Sairnaq/omarchy-theme-elf.git
cd omarchy-theme-elf
./install.sh
```
